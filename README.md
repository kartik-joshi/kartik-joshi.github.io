# kartik-joshi.github.io

Personal site of Kartik Joshi. One static page: plain HTML and CSS, a little vanilla JS, no build step, no trackers, no third-party scripts.

## Add a project

Edit `data/projects.js` and copy an existing block. Cards render in list order. Keep every number traceable to the project's README.

## Add a post

Edit `data/posts.js`. The Writing section and its nav link appear automatically once the list has one entry.

## Run locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.
